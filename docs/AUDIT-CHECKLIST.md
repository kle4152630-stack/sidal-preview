# 사이달 검수 기준표 (타로 전문가·웹 디자이너 관점)

대상: 사이달 메인 사이트 (첫 화면 → 고민 목록 → 질문 → 카드 선택 → 결과).
사용법: 각 항목을 "통과 / 실패 / 확인 못 함"으로 표시하고, 실패는 이유와 고칠 방법을 적는다.

## 1. 첫 인상과 흐름 (웹 디자인)
- [ ] 첫 화면에서 3초 안에 "무엇을 하는 곳인지" 알 수 있다.
- [ ] 첫 화면의 주요 행동은 한 개다 (지금은 "오늘의 한 장"과 "나의 한 걸음 찾기" 두 행동).
- [ ] 화면 순서가 한 방향으로 이어진다 (뒤로 가기가 헷갈리지 않는다).
- [ ] 버튼 이름이 행동을 말한다 ("다음", "시작" 같은 모호한 말을 쓰지 않는다).
- [ ] 같은 역할의 버튼이 화면마다 같은 위치에 있다.

## 2. 모바일 (폭 390px 기준)
- [ ] 가로 스크롤이 생기지 않는다.
- [ ] 글씨 최소 15px 이상, 본문은 줄 간격 1.6 이상.
- [ ] 터치 대상(버튼, 카드)은 44px 이상이다.
- [ ] 세로가 긴 결과 화면에서 핵심 문장이 한 화면 안에 들어온다.
- [ ] 키보드를 올렸을 때 입력창이 가려지지 않는다.

## 3. 카드와 해석 (타로 전문성)
- [ ] 카드 이름, 번호, 그림이 맞게 연결된다 (78장 기준).
- [ ] 결과의 해석이 뽑은 카드에서 나온다 (같은 고민에 다른 카드를 뽑으면 해석이 달라진다).
- [ ] 카드의 기본 뜻과 고민에 맞춘 해석이 구분된다.
- [ ] 해석이 "확인되는 것 / 단정할 수 없는 것 / 행동"으로 나뉜다.
- [ ] 사용자의 상황을 지어내지 않는다 (말하지 않은 감정·건강·과거를 쓰지 않는다).
- [ ] 미래 예측 표현(날짜, 확률, 성공 보장)이 없다.
- [ ] 카드 설명이 전통 타로의 상징과 맞는다 (잘못된 상징 해석이 없다).

## 4. 문구 (말투와 표현)
- [ ] 말투가 화면 전체에서 일관된다.
- [ ] 오탈자, 중복 문단, 어색한 번역투가 없다.
- [ ] 같은 문장이 여러 화면에 반복되지 않는다.
- [ ] 위로는 구체적이다 ("힘내세요" 같은 빈말을 쓰지 않는다).
- [ ] 금지 표현(확신, 단정, 예언)이 없다.

## 5. 면책과 안전
- [ ] "재미와 자기 성찰을 위한 상징 해석" 안내가 결과 화면 가까이에 작은 글씨로 있다.
- [ ] 건강·금전·법률 관련 고민에서 전문가·공적 창구를 안내한다.
- [ ] 위기 신호(자해·자살 암시)가 있으면 해석을 멈추고 109를 안내한다.
- [ ] 결제가 꺼져 있을 때 결제 관련 문구가 보이지 않는다.

## 6. 접근성
- [ ] 색 대비가 충분하다 (본문과 배경 대비 4.5:1 이상).
- [ ] 버튼에 이름이 있다 (아이콘만 있는 버튼은 설명이 있다).
- [ ] 키보드로 전체 흐름을 조작할 수 있다.
- [ ] 음성 읽어주기 같은 기능을 쓰지 않는 상태에서도 모든 정보가 전달된다.

## 7. 결제와 신뢰
- [ ] 가격과 환불 안내가 찾기 쉬운 곳에 있다.
- [ ] 결제 유도가 결과 해석을 가리지 않는다.
- [ ] 개인 메모가 외부로 전송되지 않는다는 안내가 있다.

## 8. 기술 점검 (사이달 파일 기준)
- [ ] 콘솔 오류가 없다.
- [ ] 로딩 실패 파일이 없다.
- [ ] 저장소 파일과 실제 화면 파일이 같다 (작업 폴더와 공개본의 차이 확인).

## 결과 보고 형식
1. 항목마다 통과·실패·확인 못 함 표시.
2. 실패 항목은 우선순위(높음·중간·낮음), 이유, 고칠 방법.
3. 마지막에 "지금 바로 고칠 것 5개"와 "구조를 바꿀 것 3개"로 요약.
